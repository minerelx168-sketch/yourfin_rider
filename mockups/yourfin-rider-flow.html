YourFin Rider — โฟลวการทำงานของระบบ

เซลล์ไรเดอร์ลงพื้นที่ → Backend คำนวณ/คิดคอม → ผู้บริหารเห็นเรียลไทม์ → ถอนคอม
ไรเดอร์ (Mobile) Backend + MySQL ผู้บริหาร (Dashboard) แอดมิน
1
ไรเดอร์เข้าสู่ระบบ

ไรเดอร์ล็อกอินด้วยอีเมล/รหัสผ่าน ระบบออก JWT token เก็บในเครื่อง (SecureStore) ใช้ยืนยันตัวตนทุกคำขอ

POST /auth/loginrole: SALES
2
ไรเดอร์เริ่มงาน (Clock-in)

กดเริ่มงาน → แอปจับพิกัด GPS → ส่งเข้า Backend เป็น จุดตั้งต้นของวัน (A0) ระยะทาง = 0

POST /activities/clock-inlat,lng
3
ไรเดอร์เช็คอินร้าน (ทำซ้ำหลายร้าน/วัน)

ถึงร้านพาร์ทเนอร์ → จับ GPS + ถ่ายรูปหน้าร้าน + เลือกแบรนด์ + เลือกสถานะ (ปิดดีล / รอตัดสินใจ / ปฏิเสธ) → ส่งเข้า Backend

POST /uploads (รูป)POST /activities/check-in
🗺️ คำนวณระยะทาง

หา "จุดก่อนหน้า" ของไรเดอร์คนเดิมในวันเดียวกัน → เรียก Google Maps Distance Matrix (ขับขี่จริง) → เก็บ กม./นาที (ไม่มีคีย์ใช้ Haversine แทน)

💰 คิดคอม + Affiliate

ถ้าสถานะ = ปิดดีล: ให้คอมฐานคงที่แก่ไรเดอร์ แล้วไล่จ่าย ค่าแนะนำขึ้นสาย (สูงสุด 5 ชั้น) ลงตาราง ledger

4
ไรเดอร์เลิกงาน (Clock-out) + ดูสรุป

ปิดวันทำงาน · หน้าหลักสรุป: เช็คอินวันนี้ / ปิดดีล / Conversion / ระยะทางรวม · แผนที่หมุดสีตามสถานะ

POST /activities/clock-outGET /activities/me/day
5
ผู้บริหารDashboard เห็นผลแบบ near real-time

ทุกการเช็คอินไหลขึ้น Dashboard ทันที (poll ทุก 60 วิ): KPI รวม · จัดอันดับเซลล์ · แนวโน้มรายวัน · Coverage Map · ฟีดกิจกรรม — ลดการประชุมอัปเดตงาน

GET /dashboard/overview · leaderboard · map · feed

สูตรการเงิน
• คอมต่อดีล: ปิดดีล 1 ครั้ง → ไรเดอร์ได้ commissionPerDeal (คงที่)
• ค่าแนะนำหลายชั้น: ผู้แนะนำชั้นที่ n ได้ = คอมฐาน × (referralPercent ของโหนดชั้นล่าง)%  (สูงสุด 5 ชั้น, กันสายวน)
• ยอดถอนได้ = รายได้สะสม − จ่ายแล้ว − (รออนุมัติ + อนุมัติแล้ว)
